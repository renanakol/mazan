# מאזן · תקציב משפחתי

אפליקציית ווב (PWA) בעברית למעקב חודשי ושנתי אחר הכנסות והוצאות, לפי הסעיפים של רישומית פעמונים.

## הרצה
```
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
```
ואז לפתוח http://localhost:5173

## מה יש (שלב 1)
- אשף פתיחה: שמות בני הבית ובחירת הסעיפים הרלוונטיים מתוך רשימת פעמונים
- מסך חודשי: הכנסות, הוצאות, יתרה, ביצוע מול תקציב לכל סעיף, חלוקה לפי סוגי הוצאה
- תנועות: חיפוש, סינון, סיווג לסעיף, חוקי סיווג נלמדים
- ייבוא קבצי אקסל/CSV מהבנק ומחברות האשראי, עם זיהוי עמודות, סיווג אוטומטי ודילוג על כפולות
- סיכום שנתי לפי סעיפים וסוגים, ממוצעים ותקציב שנתי
- יעדי חיסכון ויעד חיסכון חודשי
- נגישות: RTL, ניווט במקלדת, תוויות לקוראי מסך, מצב כהה, הגדלת טקסט

## ענן (שלב 2)
- Supabase, פרויקט `mazan` (eu-central-1). פרטי חיבור ב-`config.js`, הקוד ב-`cloud.js`.
- טבלאות: `households` (הגדרות, סעיפים, יעדים כ-JSON), `household_members`, `household_invites`, `transactions`. RLS: רק חברי משק הבית רואים ומשנים.
- זרימה: הרשמה/כניסה באימייל וסיסמה → פתיחת משק בית או הצטרפות עם קוד הזמנה → סנכרון הפרשים אוטומטי ועדכון בזמן אמת בין המכשירים.
- הגדרה נדרשת בלוח הבקרה של Supabase: Authentication → URL Configuration → Site URL וכתובות הפניה (http://localhost:5173 וכתובת האתר המפורסם).

## השלבים הבאים
1. **פרסום לאינטרנט** כדי לפתוח מהטלפון (למשל GitHub Pages / Netlify).
2. **סנכרון אוטומטי לקריאה בלבד**: מחבר שמושך תנועות מהפועלים/לאומי, ישראכרט/אמקס, כאל/מקס (למשל בעזרת הספרייה הפתוחה israeli-bank-scrapers) ושולח לענן. פרטי הכניסה לבנק נשמרים רק במחשב הביתי.
