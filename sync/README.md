# סנכרון אוטומטי למאזן

תוכנה שרצה במחשב הביתי, מושכת פעם ביום תנועות (קריאה בלבד) מבנק הפועלים, לאומי, ישראכרט, אמקס, כאל ומקס, ומעלה אותן לאפליקציה.
פרטי הכניסה נשמרים מוצפנים (Windows DPAPI) בקובץ `accounts.secure`, ורק המשתמש הזה במחשב הזה יכול לפענח אותו. הקובץ לא עולה ל-GitHub.

## הגדרה ראשונית (פעם אחת)
פותחים טרמינל בתיקייה הזו ומריצים:
```
node setup.js
```
1. מזינים את האימייל והסיסמה של אפליקציית מאזן.
2. מוסיפים כל חשבון: בוחרים בנק/חברת אשראי, של מי החשבון, ומזינים את פרטי הכניסה (אותם פרטים כמו באפליקציה של הבנק/הכרטיס).
3. שומרים.

## חשבונית ירוקה (הכנסות עסק צפויות)
ב-`node setup.js` בוחרים **[5] חיבור לחשבונית ירוקה** ומזינים מפתח API (יוצרים אותו בחשבונית ירוקה: הגדרות ← כלים למפתחים ← מפתחות API).
בכל סנכרון נקראים מסמכים פתוחים שעוד לא שולמו (חשבון עסקה, חשבונית מס) ומוצגים באפליקציה כהכנסות צפויות. מסמך שנסגר כשולם יורד מהרשימה. קריאה בלבד.
בדיקה של החיבור בלבד: `node sync.js --only greeninvoice`.

## הרצה ראשונה (שנה אחורה)
```
node sync.js
```
ההרצה הראשונה של כל חשבון מושכת 12 חודשים אחורה. אפשר לבחור אחרת: `node sync.js --months 6`.
בדיקה של חשבון אחד: `node sync.js --only max:m1`. הצגת הדפדפן (למשל כשנדרש קוד SMS): `--show`.

## תזמון יומי
```
powershell -ExecutionPolicy Bypass -File install-schedule.ps1
```
הסנכרון ירוץ כל יום ב-07:30, ואם המחשב היה כבוי – כשהוא יידלק. כל הרצה בודקת שוב 60 יום אחורה כדי לתפוס תנועות שנקלטו באיחור, ותנועות כפולות לא נכנסות פעמיים.

## מעקב
- באפליקציה: הגדרות ← חשבונות וייבוא מציג מתי כל חשבון סונכרן ואם הייתה שגיאה.
- במחשב: הקובץ `sync.log`.
